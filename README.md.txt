# Titanic Dataset - Data Preprocessing and Exploratory Data Analysis

## Project Title

**Data Preprocessing and Exploratory Data Analysis on the Titanic Dataset**

## Project Description

This project performs data preprocessing and exploratory data analysis (EDA) on the Titanic dataset. The dataset is cleaned by handling missing values and checking duplicate records and outliers. Various statistical analyses and visualizations are used to understand the dataset and identify patterns related to passenger survival.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Visual Studio Code

## Dataset

The project uses the publicly available **Titanic Dataset** containing passenger information such as age, gender, passenger class, fare, and survival status.

The dataset file included in this repository is:

`Titanic-Dataset.csv`

## Tasks Performed

* Loaded and inspected the dataset
* Checked dataset structure and data types
* Identified and handled missing values
* Checked for duplicate records
* Performed summary statistical analysis
* Detected potential outliers using the IQR method
* Performed exploratory data analysis
* Created data visualizations
* Analyzed survival patterns based on gender and passenger class
* Created a correlation heatmap
